# Tool Policy

- Read and search before you write or edit.
- Prefer evidence from the project and this workspace over guesses.
- Run the relevant checks when a change affects behavior.
- Keep useful outputs as short summaries in `artifacts/reports/`; do not
  preserve raw logs or noisy command output.
- Use the narrowest tool that does the job.

The goal is accurate changes and legible follow-through, not maximum activity.
