Single private npm package (`@workspace/hax-design`) consumed by `apps/web` via the `@workspace/hax-design/*` exports declared in `package.json`. Internal layering follows a strict bottom-up dependency direction: `src/styles/globals.css` (OKLCH tokens + Tailwind v4 theme) → `src/lib/` (layout constants, canvas helpers, workspace-path navigation, springs) → `src/hooks/` → three component layers under `src/components/`: (1) flat shadcn/base-nova primitives (`button`, `dialog`, `sidebar`, …), (2) `agent-elements/` — domain-agnostic chat UI (messages, tool renderers, InputBar, markdown, spiral loaders), (3) `fleet-pi/` — product chrome built on top of agent-elements (layout shell, right-panel registry, Pi config panel, auth, primitives). A fourth `openui/` layer renders generative UI from protocol prompts. The `lib/pi/` directory shims protocol types without importing React. Import convention is relative inside the package; consumers import through the curated `components/fleet-pi/*` and `components/agent-elements/*` entrypoints. State ownership is split between `apps/web` (data fetch, rightPanel state, context assembly) and this package (layout shell, panel registry, resizable canvas, mobile panel).
