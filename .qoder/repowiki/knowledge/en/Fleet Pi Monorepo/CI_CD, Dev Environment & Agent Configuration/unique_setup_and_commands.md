Development container bootstraps via `pnpm install --frozen-lockfile` in postCreateCommand and sets global git safe directory on postStart. The CI pipeline uses `--filter web` to target the web workspace for tests and builds, and requires `FLEET_PI_AUTH_MIGRATION_DATABASE_URL` / `FLEET_PI_CHAT_MIGRATION_DATABASE_URL` secrets for migration-probe verification. Release workflow requires `fetch-depth: 0` to compute tag ranges for changelog generation.
