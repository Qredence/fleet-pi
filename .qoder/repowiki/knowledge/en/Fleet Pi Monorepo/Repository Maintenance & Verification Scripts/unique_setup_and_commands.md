`scripts/auth-migrate.sh` requires `FLEET_PI_AUTH_MIGRATION_DATABASE_URL` set to a neondb_owner connection string before running `npx @better-auth/cli migrate`. `scripts/verify-neon-backend.mjs` loads `.env` and `.env.local` from the repo root and needs the `neon` CLI available in PATH plus optional `NEON_AUTH_BASE_URL`/`NEON_AUTH_JWKS_URL` fallbacks. `scripts/scan-tech-debt.sh` requires ripgrep (`rg`) and python3 installed locally.
