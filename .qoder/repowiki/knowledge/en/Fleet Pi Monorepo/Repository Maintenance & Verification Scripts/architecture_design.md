Flat collection of independent CLI utilities with no shared library — each script is self-contained and invoked directly from the repo root. Two execution models are used: Bash scripts (`auth-migrate.sh`, `scan-tech-debt.sh`) that enforce strict mode (`set -euo pipefail`) and rely on external tools (ripgrep, python3, pnpm); Node.js scripts (`generate-docs.js`, `validate-agents-md.js`, `verify-neon-backend.mjs`) that use ES modules (`.mjs` or `import.meta`) and resolve paths relative to `__dirname` to locate the repo root. Dependency direction is one-way: scripts read from `apps/web`, `packages/hax-design`, `agent-workspace`, and `.neon` context files but never modify source code except for generated artifacts under `docs/` and `tech-debt-report.json`. Entry points are the shebang lines; scripts are typically invoked through `pnpm` workspace commands rather than called directly.
