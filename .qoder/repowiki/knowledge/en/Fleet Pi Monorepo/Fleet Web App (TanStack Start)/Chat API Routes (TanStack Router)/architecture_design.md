Each file under `apps/web/src/routes/api/chat/` is a TanStack Router file route declared via `createFileRoute`, mapping HTTP methods (GET/POST/PATCH/DELETE) to async handler functions imported from `@/lib/pi/chat-runtime/handlers/*`. The root `chat.ts` exposes `/api/chat` POST, while subdirectories like `new.ts`, `run.ts`, `session.ts`, `sessions.ts`, `providers.ts`, `models.ts`, `settings.ts`, etc. map to their respective REST paths. Business logic lives outside this module in `@/lib/pi/chat-runtime/handlers`, keeping routes thin adapters. Authentication is applied through `withAuthenticatedChatRequest` or `getChatAuthSession` from `@/lib/auth/chat-api-auth`, and runtime context is resolved via `resolveAppRuntimeContext()` from `@/lib/app-runtime`. Request bodies are validated with Zod schemas from `@workspace/pi-protocol/chat-protocol.zod`, and errors are normalized through `getErrorMessage`/`getResponseStatus` from `@/lib/pi/server`.
