Three-file TanStack Router setup: `router.tsx` is the single entry that constructs the router via `createTanStackRouter`, wiring in a generated `routeTree` from `./routeTree.gen`, enabling scroll restoration and intent-based preloading, and registering the router type for TypeScript inference. `routes/__root.tsx` defines the root route with `createRootRoute`, providing the HTML `<html>`/`<head>`/`<body>` shell via `shellComponent`, global `<HeadContent>` metadata (charset, viewport, title, global stylesheet), React Query's `QueryClientProvider`, a global `Toaster`, and a `NotFoundPage`. It also initializes PostHog analytics on mount. `routes/index.tsx` registers the `/` route via `createFileRoute` and renders the full chat workspace shell (`ChatWorkspaceShell`) composed of command palette, right panel context, session controls, and the `FleetPiAgentChat` component, orchestrating chat state through `usePiChat` and various `useChat*` hooks from `@/lib/pi/chat-queries`. Dependency direction is one-way: routes depend on shared libs (`@/lib/*`) and design-system components (`@workspace/hax-design/*`), while the router file depends only on TanStack Router and the generated route tree.
