This module is a flat collection of domain-specific database modules that each own their own schema, migrations, and query helpers. Chat-related logic lives under chat-postgres-_.ts files (schema, RLS policies, Neon Data API auth), Pi session persistence is split across pi-session-_.ts files (mirror, ownership, deletion, tombstones), workspace data is handled by workspace-*.ts files (indexing, projection, provenance), and user-level concerns are in user-settings.ts and user-providers.ts. All modules target Postgres via Prisma/Neon with Row Level Security enforced through generated SQL functions, while workspace indexing uses a separate local SQLite store. Tests live alongside sources in **tests**/ and mirror each domain's file naming pattern.
