The module has two distinct parts. `api-utils.ts` is a small utility library exporting `wrapApiHandler`, which takes an async handler returning a `Response` and returns a Promise<Response>`; on rejection it logs via an optional pino `Logger`, maps the error to a status code via `getResponseStatus`from`app-runtime`, and formats the message via `getErrorMessage`from`pi/server`. The `api/` directory contains only test files (`.test.ts`) that exercise the actual route handlers located under `../../routes/api/*`; these tests import handlers like `chatProvenanceHandler`, `chatRunHandler`, `chatRunsHandler`, and `healthHandler`directly and assert on`Response`objects. There is no runtime source code in`api/` — it is a test-only package co-located with the utility.
