This module is a flat collection of shared utilities plus feature-scoped subdirectories (analytics, api, auth, daytona, db, deployment, pi, pii, storage, workspace) that are imported by the web app's server and client code. Cross-child wiring is achieved through a small set of shared primitives: `app-runtime.ts` exposes `AppRuntimeContext` (projectRoot, workspaceRoot, optional workspace bootstrap/FS) used by workspace, daytona, and deployment; `env-manager.ts` provides atomic `.env.local` mutation with process.env mirroring so all children can read updated config without restarts; `logger.ts` exports a single pino logger instance with redaction rules consumed everywhere; `query-client.ts` supplies a singleton TanStack Query client for server-side data fetching. Each subdirectory encapsulates one concern but imports from these shared primitives rather than from each other, keeping the library horizontally composable.
