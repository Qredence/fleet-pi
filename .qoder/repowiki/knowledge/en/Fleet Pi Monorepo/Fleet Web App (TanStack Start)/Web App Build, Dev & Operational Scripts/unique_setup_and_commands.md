Run `pnpm build:vercel` to produce a Vercel-compatible `.vercel/output` bundle (runs `vite build` then `scripts/build-vercel-output.mjs`). Generate the OpenAPI spec with `pnpm generate:openapi`. Apply chat DB migrations via `pnpm chat:migrate` (requires `FLEET_PI_CHAT_MIGRATION_DATABASE_URL`). Run deployment readiness checks with `pnpm verify-deployment-readiness` (reads multiple `FLEET_PI_*` env vars). E2E tests start the dev server automatically via Playwright's `webServer` hook.
