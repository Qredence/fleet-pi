The module centers on `apps/web/package.json` which declares all npm scripts that orchestrate the build pipeline and one-off operations. `vite.config.ts` is the single entry point for the dev/build server, wiring together TanStack Start, React, Tailwind CSS v4, Tempo dev plugin, tsconfig path resolution, dotenv (loading `.env` and `.env.local` from the monorepo root), and Rollup visualizer; it also externalizes `@daytona/*` packages for SSR. `playwright.config.ts` configures parallel Chromium-based E2E tests against a locally started `pnpm --filter web dev` server. `components.json` registers shadcn/ui with aliases pointing into the shared `@workspace/hax-design` package and two remote registries (`@fluid`, `@agent-elements`). The `scripts/` directory holds independent Node/tsx CLIs, each invoked via a dedicated npm script: `generate-openapi.ts` uses `@asteasolutions/zod-to-openapi` to emit `openapi.json` from Zod schemas; `build-vercel-output.mjs` uses `@vercel/nft` to trace and assemble a Vercel Build Output API bundle under `.vercel/output`; migration/maintenance scripts (`chat-migrate.ts`, `auth-post-migrate.ts`, `quarantine-orphan-sessions.ts`, `remap-auth-user-ids.ts`) connect to Neon Postgres via `@neondatabase/serverless` Pool and apply or inspect schema state; `verify-deployment-readiness.ts` runs RLS smoke tests and validates migration ledger entries before deploy. All scripts load env from both `apps/web/.env*` and repo-root `.env*` files and exit with code 1 on failure.
