Flat collection of independent Playwright test files under `apps/web/e2e/`, each file targeting a specific feature area. Tests use `@playwright/test`'s `test.describe` / `test.beforeEach` fixtures to set up pages and mock network endpoints via `page.route()`. The large `chat-flows.e2e.ts` centralizes a shared mocked chat harness (mock models, sessions, resources, settings, workspace tree/files) that other tests can reuse by calling helper functions like `mockChatModels`, `mockChatSettings`, `mockWorkspaceTree`, etc. Each test navigates to `http://localhost:3000` (or a preview URL from `FLEET_PI_PREVIEW_SMOKE_URL`) and asserts UI behavior through accessibility roles (`[role="dialog"]`, `getByRole`) and aria attributes rather than brittle CSS selectors. There is no shared test runner config in this directory — tests are discovered by Playwright's default convention.
