Three TanStack Start file-based routes under `src/routes/`: `/api/auth/$` (`$.ts`) is a catch-all server route that delegates to either the legacy Better Auth handler (when `resolveAuthBackend()` returns `local-better-auth`, dynamically importing `@/lib/auth/legacy-better-auth-tanstack`) or the shared `auth.handler` from `@/lib/auth/server`; `/api/auth/session` (`session.ts`) is a GET endpoint that calls `auth.api.getSession` and returns the session JSON; `login.tsx` renders the `/login` page, using `useSession` from `@/lib/auth/use-auth` to guard navigation and calling `signIn.email`, `signUp.email`, and `signIn.social` providers. The login page conditionally exposes a continue-anonymous action via `isLocalAnonymousAuthAllowed()`. All routes are declared through `createFileRoute` with server-side handlers — no client-side fetch code lives here.
