`pnpm dev` starts the Vite/TanStack dev server on port 3000; `pnpm build` produces the production bundle; `pnpm build:vercel` runs the Vite build then packages output via `scripts/build-vercel-output.mjs`; `pnpm generate:openapi` regenerates `openapi.json` from route schemas; `pnpm e2e` runs Playwright against the running dev server; migration scripts include `chat:migrate`, `auth:migrate`, `quarantine-orphan-sessions`, and `remap-auth-user-ids`.
