The app is a TanStack Start monorepo package: `src/router.tsx` creates the router from an auto-generated `routeTree.gen.ts`, which imports every file under `src/routes/`. Server-side routes live alongside client routes in the same file-based structure (`routes/api/*`) and are executed by Nitro/Vite during SSR. All API route handlers delegate to shared libraries under `src/lib/` (auth, db, pi-agent, workspace, deployment, analytics) rather than implementing domain logic inline. The runtime boundary is enforced by TanStack Router's route tree — client pages use React components while server routes export handler functions. E2E tests in `e2e/` target the built dev server, and operational scripts in `scripts/` handle OpenAPI generation, Vercel packaging, database migrations, and data maintenance.
