The docs module is a flat Markdown knowledge base organized by audience and purpose rather than code layers. Top-level `.md` files (README.md, quickstart.md, agent-workspace.md, adaptive-workspace.md, api.md, architecture.md, project-structure.md, runtime-sdk-integration.md) serve as entry points and generated references. Subdirectories segment content by concern: `adr/` holds numbered Architecture Decision Records following the standard ADR template with Status/Context/Decision/Consequences sections; `wiki/` is a structured wiki with `.wiki-meta.json` declaring page order and top-level sections consumed by a wiki renderer; `pitches/` contains audience-specific pitch decks; `runbooks/` contains operator-facing deployment and incident procedures. The wiki meta file (`wiki/.wiki-meta.json`) is generated at build time and records commit hash, branch, page count, and explicit page ordering, indicating an automated documentation pipeline. There are no executable artifacts — this module is pure documentation consumed by external tooling (wiki generator, CI, human readers).
