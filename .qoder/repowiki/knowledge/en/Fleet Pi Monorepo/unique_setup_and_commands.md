Root commands run through Turbo: `pnpm dev` boots the web app, `pnpm build/lint/typecheck/test/e2e` propagate to all packages respecting dependency order. Database ops use Neon CLI (`neon:plan`, `neon:deploy`, `neon:env-pull`) and migration scripts are exposed as `auth:migrate` / `chat:migrate`. Dependency consistency is enforced via `syncpack` and dead-code detection via `knip`; code duplication via `jscpd` over apps/web/src and packages/hax-design/src.
