The root is a pnpm workspace (pnpm-workspace.yaml) declaring three packages — apps/web, packages/hax-design, packages/pi-protocol — orchestrated by Turborepo (turbo.json) which defines shared tasks (build, lint, format, typecheck, test, e2e) with cross-package dependency ordering via `dependsOn: ["^task"]`. The web app consumes @workspace/hax-design and @workspace/pi-protocol as internal dependencies; hax-design re-exports the pi-protocol types. Root-level package.json scripts delegate to turbo (`pnpm build`, `pnpm dev --filter=web`) and to individual packages via `--filter`. Cross-cutting tooling (eslint.config.js, tsconfig.json, prettier, syncpack, knip, jscpd, husky pre-commit hooks) is configured at the root and applied uniformly across all child packages through shared configs and lint-staged patterns scoped to apps/web and packages/hax-design.
