## What is Fleet Pi?

Fleet Pi is a **browser-based coding-agent workspace** that provides AI-assisted development with persistent agent context, plan mode for safe reasoning, and durable project memory. It integrates the Pi coding-agent ecosystem with modern web technologies and cloud infrastructure.

## Core Features

- **Real-time Chat Interface**: Streaming chat powered by Pi coding-agent v0.80.10 with tool calling UI
- **Plan Mode**: Read-only planning mode blocking edit/write/bash operations
- **Workspace Integration**: Agent workspace as persistent project memory (agent-workspace/)
- **Per-User Sandboxes**: Daytona integration for isolated code execution
- **Settings Hot Reload**: Per-user configuration stored in Neon JSONB
- **Generative UI**: OpenUI renderer for dynamic component output
- **Neon Managed Auth**: PostgreSQL-backed identity with RLS multi-tenancy
